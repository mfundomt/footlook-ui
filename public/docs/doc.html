FootLook documentation

FootLook is zero-interaction observability for ASP.NET Core APIs. It captures eligible HTTP requests and responses through middleware, then makes the resulting captures available for local inspection, operational metrics, and live updates.

What is FootLook?

FootLook observes the ASP.NET Core request pipeline and records method, path, status code, duration, correlation information, and optional request and response bodies. Capture processing happens in a background worker, so the original application response is not held up by persistence.

  • Capture request and response details without changing application endpoints.
  • Limit capture by path, method, content type, body size, and sampling rate.
  • Mask sensitive headers, query parameters, and body values.
  • Store captures in memory and append them to a JSONL file.
  • Stream persisted captures to connected SignalR clients.

Quickstart

FootLook targets .NET 8 and ASP.NET Core applications using the minimal hosting model.

dotnet add package FootLook.Core
using FootLook.Core.Extensions;
using FootLook.Core.Hubs;
using FootLook.Core.Options;

var builder = WebApplication.CreateBuilder(args);
builder.Services.AddFootLook(options =>
{
    builder.Configuration.GetSection("FootLook").Bind(options);
});
builder.Services.AddSignalR();

var app = builder.Build();
app.UseFootLook();

var footlookOptions = app.Services.GetRequiredService<FootLookOptions>();
app.MapFootLookEndpoints(footlookOptions);
app.MapHub<CaptureHub>("/footlook/live");
app.Run();

Configuration

{
  "FootLook": {
    "Enabled": true,
    "SamplingRate": 1.0,
    "CaptureRequestBody": true,
    "CaptureResponseBody": true,
    "MaxBodyLength": 1048576,
    "EndpointBasePath": "/footlook",
    "QueCapacity": 10000,
    "ServiceName": "OrdersApi"
  }
}
OptionPurpose
EnabledEnables or disables new captures.
SamplingRateSets the fraction of eligible requests to capture.
MaxBodyLengthLimits retained request and response body size.
EndpointBasePathSets the management API route prefix.
QueCapacitySets the bounded asynchronous capture queue capacity.

Live captures

Connect a SignalR client to /footlook/live and listen for the captureReceived event. The built-in runtime dashboard is available at /footlook.html.

Management API

MethodRoutePurpose
GET/footlook/healthChecks service health and capture state.
GET/footlook/capturesLists filtered, paged captures.
GET/footlook/captures/statsReturns aggregate request statistics.
POST/footlook/captures/pausePauses capture activity.
POST/footlook/captures/resumeResumes capture activity.

Production guidance

Protect FootLook management endpoints and the SignalR hub with authorization before exposing an application outside a trusted environment.

  • Review body capture, masking, hashing, and retention settings.
  • Exclude dashboards, probes, static paths, and other known noise sources.
  • Set clear ServiceName and EnvironmentName values.
  • Monitor reliability status for queue pressure, retries, and failed persistence.
